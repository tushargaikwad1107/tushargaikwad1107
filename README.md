## 🚀 Featured project

<table>
<tr>
<td>

### [🛡️ LinkedIn Guardian](https://github.com/tushargaikwad1107/linkedin-guardian)

A **human-in-the-loop AI agent** that runs my job search: it scouts BA / DA / APM roles across Ireland, scores each one 0-100 against my CV, drafts outreach, posts and comments in my voice, and **never sends anything without my approval**.

`9 n8n workflows` · `Groq + Gemini` · `Google Sheets console` · `Slack approvals` · `LinkedIn API` · `Docker`

**What makes it interesting:** every AI draft passes a rule-based lint in code that blocks invented numbers and false claims, and the whole system runs on free tiers by pacing calls instead of paying for capacity.
